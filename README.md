# Have You Tried Turning It Off?

One funny line from a hopeless tech support agent to a desperate customer:
the classic reboot advice, gently extended to the customer themselves.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (single line, 1–199 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
